# Как перестать скачивать обновления из чата

Лучший вариант — GitHub Releases + встроенная кнопка «Проверить обновления» и отдельный обновлятор.

1. Создайте приватный или публичный репозиторий для исходников.
2. На Windows соберите EXE через build_windows.bat.
3. Опубликуйте релиз с версией и EXE в GitHub Releases.
4. Для автоматического обновления нужен дополнительный компонент: приложение проверяет API релизов, скачивает подписанный или проверенный по SHA-256 файл, завершает работу и запускает отдельный обновлятор для замены EXE.
5. Никогда не публикуйте Brave API-ключ и личную SQLite-базу.

Эта версия ещё НЕ имеет автоматической установки обновлений: для неё требуется URL вашего репозитория и выбранный канал распространения. Можно сделать обновления без GitHub через собственный HTTPS-сервер.
